## 1) 全局布局（强烈建议固定“三栏布局”）

**顶部 Header（常驻）**

* 全局搜索框（按标题/作者/关键词/标签/数据集/方法）
* Import 按钮
* 项目选择器（Workspace）
* Export（当前论文/对比/笔记导出）
* 用户/设置

**左侧 Sidebar（常驻）**

* Library / Queue / Notes / Compare / Reviewer 快捷入口
* 标签（Tags）/领域（Domains）/数据集（Datasets）/方法（Methods）筛选树
* 最近打开（Recent）

**主区域 Main（随页面变化）**

* PDF 原文 / 结构化视图 / 对比矩阵 / 审稿报告

**右侧 Panel（常驻，可切 Tab）**

* **Enhance（阅读增强）**
* **Notes（笔记/卡片）**
* **Checklist（复现清单）**
* **Chat（对话，带上下文锚点）**
* **Tasks/Timer（时间管理/中断恢复）**

> 这样做的好处：模块3（流程）永远在主区域，模块2（增强）永远在右侧“随叫随到”。

## 2) 页面级规格（Screen → 组件 → 操作 → 产物 → 埋点）

下面按用户旅程给你最关键的 8 个页面。

### 2.1 Library（文献库页）

**目的**：快速筛选“值得读”的论文，进入粗读/精读。

**主组件**

* `FilterBar`：年份/领域/任务/数据集/方法/期刊会议/质量等级
* `PaperList`（每条 `PaperListItem`）

  * `QualityBadge`（证据强度 A/B/C/D）
  * `ReproBadge`（复现信息齐/缺）
  * `StatusChip`（未读/粗读/精读/已归档）
  * `OneLineContribution`
* `BulkActions`：加入队列/打标签/导出 BibTeX

**关键按钮**

* 打开论文
* 一键粗读（生成 SkimCard）
* 加入待读队列（带优先级/预估时间）

**产物**

* 阅读列表 + 初步质量判断（可作为“阅读决策记录”）

**埋点事件（示例）**

* `library_opened`
* `library_filter_applied`
* `paper_list_item_opened`
* `paper_added_to_queue`

---

### 2.2 Import（导入/解析页）

**目的**：导入 PDF/DOI/arXiv/URL，解析结构与锚点。

**主组件**

* `ImportDropzone`（PDF/URL/DOI）
* `MetadataConfirm`（标题、作者、年份、venue）
* `ParseProgress`（章节/参考文献/图表/公式提取状态）
* `ParseErrorPanel`（失败原因 + 解决建议）

**关键按钮**

* Confirm & Parse
* Retry / Manual Fix（比如手动输入 DOI）

**产物**

* 可定位的结构化论文对象（章节/图表/公式都有锚点）

**埋点**

* `paper_import_started`
* `paper_import_succeeded`
* `paper_parse_failed`（带 error_code）

---

### 2.3 Paper Overview（论文总览 / 粗读页）

**目的**：3–7 分钟做阅读决策（读/不读/放队列/直接精读）。

**主组件（主区）**

* `SkimCard`（核心）

  * Research Question
  * Claimed Contributions（可验证表述）
  * Evidence Strength（强/中/弱 + 原因）
  * Red Flags（统计/评估/复现风险）
  * Recommended Route（建议先读哪些段/哪些图）
* `FigureGallery`（关键图表缩略 + 一键解读）
* `RelatedPapersMiniMap`（同类/对立/经典/最新 4 组各 3 篇）

**关键按钮**

* `DecisionButtons`: **Archive / Add to Queue / Start Deep Read**
* `Start Reviewer Mode`
* `Start Compare Mode`

**右侧 Panel（Enhance）在粗读页常用**

* 术语速查、图表解读、背景补齐

**产物**

* `SkimCard` + 决策记录（为什么读/不读）

**埋点**

* `skim_generated`
* `skim_decision_made`（decision=archive|queue|deepread）
* `figure_explain_opened`

---

### 2.4 Deep Read（精读/阅读器页：PDF+结构化）

**目的**：按路线读，读完直接生成“可复现 + 可写作 + 可对比”的产物。

**主组件（主区）**

* `ReaderHeader`

  * 进度条、预计剩余时间
  * 当前模式（DeepRead）
* `SplitView`（可切换）

  * 左：`PDFViewer`（高亮/定位/批注）
  * 右：`StructuredView`（按章节抽取：方法/实验/结论）
* `RoutePlanner`（必须读段落/关键图表路线）
* `SectionNavigator`（章节树 + 完成勾选）
* `EvidenceLedger`（主张→证据→不确定性：自动生成可编辑）

**右侧 Panel（四个 Tab 最常用）**

* **Enhance**：术语/公式/图表/缺失细节补全（随选中内容变化）
* **Notes**：卡片编辑器（边读边沉淀）
* **Checklist**：复现清单（自动抽取 + 缺失项提醒）
* **Chat**：围绕选中文本对话（带引用锚点）

**关键按钮**

* `CreateCard`（从选中段落/图表一键生成 EvidenceCard）
* `AddToChecklist`（把关键超参/数据切分加入复现清单）
* `MarkSectionDone`
* `Pause/Resume`（中断恢复）

**产物**

* PaperCard / MethodCard / EvidenceCard
* ReproChecklist
* 引用片段（可导出写 related work）

**埋点**

* `deepread_started`
* `section_marked_done`
* `enhance_panel_opened`（type=term|equation|figure|missing_detail）
* `card_created`（card_type）
* `checklist_item_added`
* `deepread_paused` / `deepread_resumed`
* `deepread_completed`

---

### 2.5 Reviewer Mode（审稿页）

**目的**：以审稿人结构输出 + 精准 Questions for Authors。

**主组件**

* `ReviewerRubric`

  * Novelty / Soundness / Rigor / Reproducibility / Clarity（每项打分+理由）
* `ClaimsAndEvidenceTable`（每条 claim 对应证据锚点）
* `QuestionsForAuthors`（可编辑，支持一键转“组会提问”）
* `RecommendationPicker`（强收/弱收/弱拒/强拒）

**关键按钮**

* Generate Review Report
* Export（PDF/Markdown）

**产物**

* ReviewReport（可追溯到原文锚点）

**埋点**

* `review_mode_entered`
* `review_report_generated`
* `review_question_added`
* `review_exported`

---

### 2.6 Compare Mode（对比页）

**目的**：同类论文对齐指标/数据/设定，生成对比矩阵与冲突图谱。

**主组件**

* `CompareSetBuilder`（选择对比论文：同任务/同数据/对立/替代）
* `NormalizationPanel`

  * 术语归一（同义映射）
  * 指标归一（如 Acc/F1/AUC）
  * 数据设定对齐（split、preprocess）
* `CompareMatrix`（核心差异点表）
* `ConflictMap`（结论冲突：谁支持谁反对，证据强度）

**关键按钮**

* Add Paper to CompareSet
* Export Matrix（Word/Markdown/CSV）
* Save as “Related Work Scaffold”（相关工作骨架）

**产物**

* CompareMatrix + ConflictMap + 最佳实践总结

**埋点**

* `compare_mode_entered`
* `compare_set_created`
* `compare_normalization_applied`
* `compare_matrix_exported`

---

### 2.7 Notes（笔记库页）

**目的**：把卡片变成可检索资产，写作时一键聚合。

**主组件**

* `NotesSearch`（按任务/方法/数据集/关键词/引用）
* `CardGrid`（按类型过滤）
* `CardDetail`（显示来源锚点、引用格式、反向链接）
* `Collections`（按 workspace/论文串/主题）

**关键按钮**

* Export selected cards
* Generate related-work section draft（输出骨架，不直接抄原文）

**埋点**

* `notes_opened`
* `card_opened`
* `card_exported`
* `notes_collection_created`

---

### 2.8 Chat（对话页：研究协作）

**目的**：不是闲聊，而是带上下文锚点的“科研协作”。

**主组件**

* `ChatThread`
* `ContextDock`（当前对话引用了哪些段落/图表/卡片）
* `ModeSwitch`（组会模式/写作模式/复现模式/方案设计模式）
* `ActionSuggestions`（“把这段变成 EvidenceCard”“加入复现清单”“生成对比问题”）

**埋点**

* `chat_opened`
* `chat_message_sent`
* `chat_mode_switched`
* `chat_action_clicked`

## 4) 埋点事件命名规范（你可以直接给数据/后端）

### 4.1 命名规范

* 统一前缀按域：`paper_` `skim_` `deepread_` `enhance_` `card_` `review_` `compare_` `chat_` `export_`
* 用过去式表达发生：`_started/_succeeded/_failed/_opened/_created/_exported`

### 4.2 建议的核心事件（MVP 必备）

**导入与解析**

* `paper_import_started` {source_type, file_size_mb}
* `paper_import_succeeded` {paper_id, parse_time_ms}
* `paper_parse_failed` {error_code}

**粗读**

* `skim_generated` {paper_id, latency_ms}
* `skim_decision_made` {paper_id, decision, reason_tags[]}

**精读**

* `deepread_started` {paper_id}
* `section_marked_done` {paper_id, section_id}
* `deepread_paused` / `deepread_resumed` {paper_id, anchor_id}
* `deepread_completed` {paper_id, duration_s}

**增强引擎**

* `enhance_panel_opened` {paper_id, type, anchor_id}
* `enhance_level_switched` {type, level}
* `missing_detail_flagged` {missing_type}

**结构化资产**

* `card_created` {paper_id, card_type, anchor_id}
* `card_edited` {card_type}
* `checklist_item_added` {item_type}

**对比/审稿/导出**

* `compare_set_created` {size}
* `compare_matrix_exported` {format}
* `review_report_generated` {score_overall}
* `export_triggered` {object_type, format}

**对话协作**

* `chat_message_sent` {mode, has_context_anchor}
* `chat_action_clicked` {action_type}
