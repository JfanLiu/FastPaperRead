## 0) 全局壳（所有页面通用）

**Header（顶栏，固定）**

* 左：Logo + Workspace 下拉（当前课题空间）
* 中：全局搜索框（论文/作者/术语/卡片/数据集）
* 右：Import 按钮｜Export（随页面变化）｜用户菜单

**Left Sidebar（左栏，固定）**

* 导航：Library / Queue / Notes / Compare / Reviewer / Chat
* 筛选树（可折叠）：Tags / Domains / Datasets / Methods
* Recent 最近打开（可选）

**Right Panel（右栏，固定，可收起）**

* Tab：Enhance / Notes / Checklist / Chat / Timer
* 默认：在阅读器类页面打开；在列表页可收起

---

## 1) Library（文献库页）线框图

**页面目标**：搜到“值得读”的论文，并一键粗读/加队列/打开。

**布局示意**

```
[Header: Workspace | Search | Import | Export]
[Sidebar Nav + Filters] | [Main: Library List] | [Right Panel (optional)]
```

**Main（中间主区）从上到下**

1. `PageTitle + Stats`

* 标题：Library
* 统计：总数、未读、粗读、精读、A/B/C/D 分布小条（可点筛选）

2. `FilterBar（横向条）`

* 年份范围、Venue、质量等级、复现可用性、排序（相关性/最新/证据强度）
* Saved Presets（“我的常用筛选”）

3. `PaperList`

* 每条 PaperListItem（从左到右）：

  * Checkbox（批量）
  * 标题（可点进论文）
  * 作者+年份+Venue
  * `QualityBadge(A/B/C/D)`（hover 弹出原因）
  * `ReproBadge(齐/缺)`（hover 展示缺失项）
  * 一句话贡献（OneLineContribution）
  * 快捷操作：Skim / Add to Queue / Open

4. `BulkActions（浮动或列表上方）`

* 批量：加入队列、打标签、导出 BibTeX、加入对比集合

**右侧（可选）Preview Drawer**

* 点某篇时右侧显示“预览卡”：标题、摘要、关键图表缩略、推荐阅读层级

**关键交互**

* 点击 `Skim`：后台生成 SkimCard → 弹出小卡片预览 → 可直接“精读/归档/加入队列”
* 鼠标悬停 QualityBadge：显示“证据强度解释 + 红旗”
* 批量勾选后，BulkActions 出现

**空状态**

* “还没有论文” → 引导 Import / 粘贴 DOI / arXiv / URL
* 筛选后无结果 → 提示放宽条件 + 一键重置

## 2) Import（导入/解析页）线框图

**页面目标**：导入 → 确认元数据 → 解析成功后进入 Overview。

**布局示意**

```
[Header]
[Sidebar] | [Main: Import Wizard (stepper)] | [Right Panel hidden]
```

**Main（导入向导）**

1. `Stepper（步骤条）`

* Step1 上传/粘贴 → Step2 元数据确认 → Step3 解析中 → Step4 完成

2. Step1：`ImportDropzone`

* 大拖拽区：PDF
* 下方：输入 DOI/arXiv/URL 的文本框 + 粘贴按钮
* 支持：批量导入（可选）

3. Step2：`MetadataConfirm`

* 左：自动识别的标题/作者/年份/Venue（可编辑）
* 右：来源信息（DOI 链接/ArXiv ID）+ PDF 预览缩略
* 底部：Confirm & Parse

4. Step3：`ParseProgress`

* 进度条 + 分项状态：

  * 章节提取 ✅/⏳
  * 参考文献 ✅/⏳
  * 图表 ✅/⏳
  * 公式 ✅/⏳
* “解析后可做什么”提示（生成锚点、结构化阅读）

5. Step4：完成

* 显示论文卡（标题、质量初筛）
* 两个大按钮：Open Overview / Add to Queue

**异常/失败状态（ParseErrorPanel）**

* 显示错误码：如 PDF 文本层缺失、加密、乱码
* 解决方案：

  * 重新上传更清晰 PDF
  * 仅使用 DOI 拉取
  * 手动选择“图片型PDF模式”（如后续要支持OCR）

## 3) Paper Overview（粗读/总览页）线框图

**页面目标**：3–7 分钟完成“读不读”的决策，并能一键进入精读/审稿/对比。

**布局示意**

```
[Header (Export=SkimCard/Notes)]
[Sidebar] | [Main: Overview] | [Right Panel: Enhance (default)]
```

**Main（从上到下）**

1. `PaperHeader`

* 标题 + 作者 + 年份 + Venue
* 快捷：PDF / BibTeX / Cite
* 状态：未读/粗读/精读

2. `DecisionBar（固定在 PaperHeader 下）`

* Archive（归档原因下拉）
* Add to Queue（优先级+估时）
* Start Deep Read（主按钮）
* Secondary：Reviewer / Compare

3. `SkimCard（核心）`

* RQ（研究问题）
* Contributions（3点）
* Evidence Strength（强/中/弱 + 为什么）
* Red Flags（可展开）
* Recommended Route（建议先读哪些章节/图表）

4. `Key Figures Strip（关键图带）`

* 4–8 张缩略图 + caption
* 点击 → 弹出 Figure Viewer（附图解读）

5. `Mini Literature Map（小型文献地图）`

* 四栏：经典 / 最新 / 同类 / 对立
* 每栏 3 篇，按钮：加入对比、加入队列

**Right Panel（Enhance Tab）默认内容**

* “选中内容解释”：术语/背景（默认通俗版）
* “图表解读”：当你点图时自动切换
* “缺失细节扫描”：粗读时可一键跑一遍

**空状态**

* 若还没生成 SkimCard：显示“一键粗读”大按钮 + 预计用时

## 4) Deep Read（精读阅读器页）线框图

**页面目标**：按路线读 + 边读边沉淀卡片 + 可复现清单自动抽取 + 中断恢复。

**布局示意（经典三栏）**

```
[Header: mode=DeepRead | progress | timer | export]
[Sidebar] | [Main: SplitView PDF <-> Structured] | [Right Panel: Enhance/Notes/Checklist/Chat/Timer]
```

**Main 顶部：`ReaderToolbar`**

* 进度：Section 完成度（xx%）
* Route：必读路线（下拉切换）
* 搜索：在本文内搜术语
* Pause / Resume
* “生成产物”快捷：生成 PaperCard、导出当前卡片

**Main 主体：`SplitView`（可左右可切）**

* 左半：`PDFViewer`

  * 章节跳转、页码
  * 高亮/批注（右键菜单）
  * 图表点击可“Explain figure”
* 右半：`StructuredView`

  * 当前章节摘要（严格版）
  * 方法流程图（可折叠）
  * 实验设置复原块（数据/指标/baseline）

**Main 底部：`EvidenceLedger（可折叠抽屉）`**

* Claim 列表（每条可展开：证据锚点 + 不确定性）
* 一键“生成 EvidenceCard”

**Right Panel Tabs（非常关键）**

1. Enhance

* TermExplainer（三层切换：一句话/通俗/严格）
* EquationExplainer（符号表 + 假设）
* FigureExplainer（图想证明什么 + 替代解释）
* MissingDetailFinder（推测补全 + 待原文确认清单）

2. Notes

* Card 列表（本论文）
* 当前编辑卡片（带锚点引用）
* 快捷：从选中文字/图 → “生成卡片”并自动填充

3. Checklist

* ReproChecklist（分组：数据/预处理/训练/评估/环境）
* 缺失项提醒（红点）
* “转为实验计划”（可选二期）

4. Chat

* 带上下文的对话（自动附上选中锚点）
* 推荐动作按钮：加入清单 / 生成卡片 / 提一个审稿问题

5. Timer

* 番茄钟 + 本次目标（读完方法/读完实验）
* Resume Point（上次停的位置，一键回跳）

**中断恢复**

* 页面顶部出现 `ResumeBanner`：上次停在第X页/某段落 → “回到上次位置”

**空状态**

* 第一次精读：RoutePlanner 引导弹窗（先读哪些段/图）

## 5) Reviewer Mode（审稿页）线框图

**页面目标**：快速形成审稿结构 + 问题清单 + 结论建议（可追溯锚点）。

**布局示意**

```
[Header: Export Review]
[Sidebar] | [Main: Review Report Builder] | [Right Panel: Evidence/Enhance/Chat]
```

**Main 从上到下**

1. `ReviewHeader`

* 论文信息 + 当前总体建议（未选择时显示占位）
* “生成审稿草稿”按钮（基于已有 EvidenceLedger/卡片）

2. `ReviewerRubric（评分区）`

* Novelty / Soundness / Rigor / Reproducibility / Clarity
* 每项：分数滑条 + 理由文本框（可自动填充，可编辑）

3. `ClaimsAndEvidenceTable`

* 左列 Claim，右列 Evidence anchors（点击跳到 PDF）
* 红旗标记（例如：无消融、疑似泄漏）

4. `QuestionsForAuthors`

* 3–8 条问题列表（可排序、可标记“必须回答”）
* 一键转换为“组会提问稿”

5. `RecommendationPicker`

* 强收/弱收/弱拒/强拒 + 置信度
* 输出总结段落（可导出）

**Right Panel**

* 默认：Evidence（从卡片/ledger 拉过来）
* 可切 Enhance（解释统计/方法疑点）
* Chat（跟“审稿合作者”讨论）

## 6) Compare Mode（对比页）线框图

**页面目标**：把几篇论文“对齐后比较”，得到对比矩阵 + 冲突图谱 + 最佳实践。

**布局示意**

```
[Header: Export Matrix]
[Sidebar] | [Main: Compare Workspace] | [Right Panel: Normalization/Notes]
```

**Main 分三段（上中下）**

1. `CompareSetBuilder（上）`

* 左：已选论文 chips（可拖拽排序）
* 右：Add paper（搜索/从推荐四类加入：同类/对立/经典/最新）
* 显示：集合规模 + 覆盖提示（数据集/指标是否一致）

2. `NormalizationPanel（中，关键）`

* 术语归一：表单式映射（“Method A == Method A+”）
* 指标归一：选择主指标（AUC/F1/Acc）并标注不可比项
* 数据设定对齐：split、预处理、训练预算
* “应用归一化”按钮

3. `CompareMatrix + ConflictMap（下）`

* CompareMatrix：行=论文，列=数据/方法/指标/结果/成本/局限/复现性
* ConflictMap：对同一结论不同论文的支持/反对（按证据强度加粗）

**Right Panel**

* Notes：把对比结论一键生成“Related Work 骨架卡片”
* 或显示“差异点总结”（可编辑）

**空状态**

* 少于 2 篇论文：提示添加 + 推荐同类论文

## 7) Notes（笔记库页）线框图

**页面目标**：像管理知识库一样管理卡片，并支持写作前一键聚合。

**布局示意**

```
[Header: Export Selected]
[Sidebar] | [Main: Notes Library] | [Right Panel: Card Detail]
```

**Main 左侧（主列表区）**

1. `NotesSearch + Filters`

* 搜索：关键词/术语/数据集/方法/claim
* 过滤：Card 类型、workspace、时间、证据强度

2. `CardGrid/List`

* 卡片缩略：标题、类型、来源论文、标签、更新时间
* 多选框（批量导出/合并）

**Main 右侧（可选，或放到 Right Panel）**

* `CardDetail`

  * 卡片正文（可编辑）
  * 来源锚点（点击跳回 PDF）
  * 反向链接：相关卡片/对比集合/审稿问题

**顶部动作**

* “生成 related work 骨架”（选择一组卡片 → 输出段落结构）
* “导出 Markdown/Notion/Word”

**空状态**

* 还没有卡片：引导去精读页生成 PaperCard/EvidenceCard

## 8) Chat（对话页）线框图

**页面目标**：带上下文锚点的科研对话（不是闲聊），支持“对话→动作”。

**布局示意**

```
[Header: mode switch | export chat notes]
[Sidebar] | [Main: Chat Thread] | [Right Panel: Context Dock + Actions]
```

**Main**

1. `ModeSwitch（顶部）`

* 组会模式 / 写作模式 / 复现模式 / 方案设计模式

2. `ChatThread（中部）`

* 消息气泡
* 每条消息可带“引用锚点”小标签（点击展开证据）

3. `Composer（底部输入区）`

* 输入框 + 附加上下文按钮（选择论文/卡片/段落）
* 快捷按钮：提炼问题 / 生成实验建议 / 生成对比问题

**Right Panel：Context Dock（核心）**

* 当前对话引用了哪些：

  * Paper(s)
  * Card(s)
  * Anchor(s)（段落/图表）
* `Action Suggestions`

  * “把这段生成 EvidenceCard”
  * “加入复现清单”
  * “加入对比集合”
  * “生成审稿问题”

**空状态**

* 没有上下文：提示选择论文或从阅读器跳转到 Chat（携带锚点）
