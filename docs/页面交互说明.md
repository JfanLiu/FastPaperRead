## A) 全局交互规范（所有页面通用）

### A1. 三种“动作反馈”形态

1. **Toast（轻提示）**：已加入队列/已生成卡片/已导出
2. **Inline 状态**：列表项出现 Badge、进度条、红点
3. **Blocking Modal（阻塞弹窗）**：导入确认、归一化确认、导出配置、删除等

### A2. 全局对象状态（建议统一）

* Paper.status：`unread` / `skimmed` / `deepread` / `archived`
* Paper.queue_status：`none` / `queued` / `in_progress` / `done`
* Card.status：`draft` / `final`
* Anchor：`paragraph` / `figure` / `table` / `equation`

### A3. “可追溯”交互原则（科研工具必备）

* 任何生成内容（SkimCard、EvidenceCard、Review）都要显示：

  * **来源锚点**（点击跳转原文）
  * **不确定性标签**（来自原文/推测补全/需确认）
  * **最后更新时间 & 修改者（用户/AI）**

## B) 页面交互说明（逐页）

## 1) Library（文献库页）交互

### 1.1 搜索/筛选

* 用户在 FilterBar 选择：年份/领域/质量等级/复现可用性
* 系统：

  * 立即刷新列表（支持防抖）
  * 在 Header 下显示“当前筛选条件 chips”（可一键清除某个）
  * URL（或内部路由状态）记录筛选，方便分享/回到同视图

**空结果**：展示“放宽筛选”建议按钮（如取消 venue 限制、质量从 A/B 放到 A/B/C）

### 1.2 列表项操作（每篇论文）

* 点击标题 → 进入 **Paper Overview**
* 点击 `Skim`：

  * 若未生成过：进入后台生成 → 列表项出现 loading spinner
  * 完成后：弹出 `Skim Preview Popover`（小预览卡）+ 三个按钮：Archive / Add to Queue / Deep Read
* 点击 `Add to Queue`：

  * 打开 `QueueConfig Drawer`（优先级、估时、目的：读方法/读实验/全读）
* 点击 `QualityBadge`：

  * 展示 `QualityReason Popover`（证据强度理由 + 红旗）
* 多选 + BulkActions：

  * 批量加入队列（同配置 or 分别配置）
  * 批量打标签
  * 批量导出 BibTeX/CSV

---

## 2) Import（导入/解析页）交互

### 2.1 导入入口

* 拖拽 PDF / 粘贴 DOI/arXiv/URL
* 系统：创建 ImportJob，进入 Step2（元数据预填）

### 2.2 元数据确认（Step2）

* 用户可编辑：标题、作者、年份、Venue、关键词
* 点击 `Confirm & Parse`：

  * 进入 Step3，展示分项进度（sections/refs/figures/equations）
  * 解析完成 → Step4（完成页）
  * 解析失败 → `ParseError Modal`（错误码 + 解决建议 + Retry）

### 2.3 完成后的去向（Step4）

* `Open Overview`：进入 Paper Overview
* `Add to Queue`：弹出 QueueConfig Drawer
* `Import Another`：回到 Step1

---

## 3) Paper Overview（粗读/总览）交互

### 3.1 “一键粗读”

* 如果还没有 SkimCard：

  * 点击 `Generate Skim`：

    * 主区出现 skeleton（占位）
    * 右下角 toast：正在生成（可后台继续，用户可浏览其他内容）
    * 生成完成：SkimCard 填充 + 自动滚动到 SkimCard 顶部（可选）

### 3.2 决策栏（DecisionBar）

* `Archive`：

  * 弹 `ArchiveReason Modal`（原因多选：不相关/证据弱/复现风险/重复/时间不够）
  * 提交后：Paper.status=archived，回 Library 时默认隐藏（可在筛选里显示“已归档”）
* `Add to Queue`：

  * 打开 `QueueConfig Drawer`
* `Start Deep Read`：

  * 若第一次精读：弹 `RoutePlanner Modal`（推荐路线 + 估时 + 可自定义）
  * 确认后进入 Deep Read，并在 Timer 中创建一次阅读 session（本地状态）

### 3.3 关键图表（FigureGallery）

* 点击缩略图：

  * 打开 `FigureViewer Modal`
  * Modal 内按钮：Explain（触发 FigureExplainer）/ Create EvidenceCard / Jump to PDF location

### 3.4 Mini Literature Map（四栏推荐）

* 点击某篇：

  * `Open in new tab`（可选）
  * `Add to CompareSet`（进入对比集合侧栏，提示已加入）
  * `Add to Queue`

---

## 4) Deep Read（精读阅读器）交互

### 4.1 进入精读：路线规划

* 第一次进入时：

  * `RoutePlanner Modal`：系统给 2–3 个路线：

    1. 快速复现路线（方法+实验设置+关键图）
    2. 审稿路线（主张→证据→局限）
    3. 全文路线（按章节）
  * 用户确认后：生成 `Must-read checklist`（章节勾选清单）

### 4.2 PDF Viewer 基本交互

* 选中文本（拖拽选择）→ 弹出 `Selection Toolbar`（小浮条）：

  * Explain term(s)
  * Summarize this paragraph (strict/plain)
  * Create EvidenceCard
  * Add to ReproChecklist
  * Quote snippet (生成可改写引用骨架)
  * Highlight / Annotate
* 点击图表/公式区域（有锚点）：

  * 右侧 Enhance 自动切到 FigureExplainer / EquationExplainer
  * 可在浮条直接 `Explain` 或 `Create Card`

### 4.3 Structured View 交互

* 章节树点击：

  * PDF 同步跳转到对应页（双向同步可开关）
* “方法复原块”可折叠：

  * 展开后出现：输入/输出/假设/流程/复杂度/伪代码（如可生成）
* “实验设置复原块”按钮：

  * `Extract to Checklist`：把数据切分、指标、baseline 一键加入 ReproChecklist

### 4.4 Notes（卡片）交互

* `CreateCard`（从选中内容创建）：

  * 打开 `CardComposer Drawer`（右侧抽屉）
  * 自动填：标题、类型（Evidence/Method）、正文草稿、引用锚点
  * 用户编辑后 `Save`：

    * Card.status=draft/final（可选）
    * 出现 toast：已保存到 Notes
* `Convert to PaperCard`（完成精读后）

  * 系统根据已有卡片合成 PaperCard（用户可改）

### 4.5 ReproChecklist 交互

* Checklist 分组：Data / Preprocess / Training / Eval / Env
* 每个条目支持：

  * `source anchor`（点击回原文）
  * `missing flag`（缺失项红点：比如“训练轮数未说明”）
  * `need verify`（推测补全项需确认）
* 一键按钮：

  * `Find missing details`：扫描全文找关键复现字段缺失（不确定项列表）

### 4.6 Evidence Ledger（主张-证据台账）交互

* 列表每条 claim：

  * 展开：证据锚点、强度评级、替代解释、风险点
  * `Promote to EvidenceCard`（固化成卡片）
* `Add claim`：用户自己写 claim，系统建议该去找哪些段落/图表支持

### 4.7 Timer & 中断恢复

* 点击 Pause：

  * 记录 last_anchor + 当前 tab
  * 下次进来顶部出现 `ResumeBanner`：一键回跳
* 番茄钟结束：

  * 弹 `SessionWrap Modal`：本次读了哪些章节？生成了哪些卡片？下一步要做什么（自动建议）

---

## 5) Reviewer Mode（审稿）交互

### 5.1 自动生成审稿草稿

* 点击 `Generate Draft Review`：

  * 系统优先使用：EvidenceLedger + Cards + ReproChecklist
  * 生成 Rubric 理由、Claims/Evidence 表、Questions
  * 每个结论都带锚点链接（可点回 PDF）

### 5.2 评分与理由编辑

* 每项 Rubric：

  * 调分 → 系统提示“会影响总体建议”
  * 理由支持自动补全（但用户必须可删改）

### 5.3 Questions for Authors

* 每条问题可标记：

  * Severity（Major/Minor）
  * Topic（实验/方法/统计/复现/写作）
* 一键导出“组会提问稿”：

  * 自动排序：Major 在前 + 关联到对应图表/段落

---

## 6) Compare Mode（对比）交互

### 6.1 建集合

* Add paper：支持搜索 + 从“推荐组（同类/对立/经典/最新）”添加
* 进入集合后：

  * 系统提示“对齐风险”：比如指标不同、数据集不同（显示黄条）

### 6.2 归一化（Normalization）

* 用户在 NormalizationPanel 做映射：

  * 术语同义归并（拖拽/下拉）
  * 指标映射（如 Acc vs F1：提示不可直接比）
  * 训练预算对齐（epochs、params、GPU hours）
* 点击 `Apply`：

  * CompareMatrix 刷新
  * ConflictMap 更新（冲突更明显）

### 6.3 矩阵与冲突图交互

* 矩阵单元格点击：

  * 打开 `CellDetail Modal`：显示该结论来自哪段/哪图 + 证据强度
* “生成 related work 骨架”

  * 输出结构：按路线（时间线/方法流派/数据集）三选一

---

## 7) Notes（笔记库）交互

### 7.1 搜索与聚合

* 用户输入：数据集名/方法名/claim 关键词
* 系统返回卡片并按：

  * 相关性 + 证据强度排序
* 选择多张卡 → `Generate Writing Scaffold`：

  * 输出 related work 的段落骨架（只给“可改写结构”，不复制原句）

### 7.2 卡片生命周期

* Draft → Final：

  * Final 需要用户勾选“已核对原文锚点”
* 卡片版本：

  * 可选二期：History（对比修改）

---

## 8) Chat（对话）交互

### 8.1 上下文挂载

* 从阅读器跳转到 Chat：

  * 自动带上当前 anchor + 已打开卡片
* Chat 输入框旁：

  * `Attach context`：选择论文/卡片/对比矩阵/审稿草稿

### 8.2 模式切换

* 组会模式：系统会更“打断式追问”
* 写作模式：系统会输出段落骨架 + 引用卡片集合
* 复现模式：系统优先询问缺失项并生成实验计划清单
* 方案设计模式：系统给多方案并标注风险与资源需求

### 8.3 对话→动作

* 每条助手回复下方：

  * `Create EvidenceCard`
  * `Add to Checklist`
  * `Add to Compare`
  * `Turn into Review Question`

# C) 关键弹窗/抽屉/浮层清单（建议做成统一组件库）

## C1. Modal（阻塞弹窗）

1. `ArchiveReason Modal`：归档原因（多选 + 自定义备注）
2. `RoutePlanner Modal`：精读路线（模板 + 自定义 + 估时）
3. `FigureViewer Modal`：大图查看 + Explain + 生成卡片
4. `ParseError Modal`：错误码 + Retry + 建议
5. `ExportConfig Modal`：导出对象（Skim/Notes/Compare/Review）+ 格式（MD/Docx/PDF/CSV）
6. `SessionWrap Modal`：一次阅读 session 总结 + 下一步

## C2. Drawer（右侧抽屉）

1. `QueueConfig Drawer`：优先级、估时、目标（方法/实验/全读）
2. `CardComposer Drawer`：创建/编辑卡片（自动填充 + 锚点）
3. `ChecklistDetail Drawer`：复现条目细化（字段、来源、缺失标记）
4. `CompareSet Mini Drawer`：当前对比集合管理（快速增删）

## C3. Popover/Tooltip（轻浮层）

1. `QualityReason Popover`：证据强度解释 + 红旗
2. `ReproBadge Popover`：缺失字段列表
3. `Citation Popover`：BibTeX/GB/T/APA 快速复制
4. `Uncertainty Tag Tooltip`：原文/推测/需确认说明

---

# D) 右键菜单与选中浮条（阅读器内最关键）

## D1. 选中文本浮条（Selection Toolbar）

* Explain（术语/段落：一句话/通俗/严格）
* Create EvidenceCard
* Add to Checklist
* Quote snippet（生成可改写引用骨架）
* Highlight（颜色可后配）
* Add annotation（批注）

## D2. 图表右键菜单

* Explain this figure
* Extract numbers (如果可做：提取表格/曲线关键数值)
* Create EvidenceCard (link figure)
* Add as key figure（加入路线/摘要）

## D3. 公式右键菜单

* Explain equation (symbol table)
* List assumptions
* Where used (定位论文中使用该式的段落)
* Create MethodCard snippet

---

# E) 通知与后台任务（不打扰科研人）

* 生成 Skim/Review/Matrix 这种任务：

  * **可离开页面**后台跑
  * 完成后 toast + Library/Overview 出现“已生成”标记
* 长任务失败：toast + 任务中心（可选）显示失败原因与重试

---

# F) 快捷键（提升效率，强建议加）

* `S`：生成/打开 SkimCard
* `D`：进入 Deep Read
* `C`：创建卡片（基于当前选中）
* `R`：进入 Reviewer Mode
* `M`：进入 Compare Mode
* `Ctrl/Cmd + K`：全局搜索
* `Ctrl/Cmd + Enter`：在 Chat 发送并附带当前上下文锚点（可选）
